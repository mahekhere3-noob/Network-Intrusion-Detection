# 🛡️ Network Intrusion Detection

## 📌 Overview

This project uses Machine Learning to detect network intrusions by analyzing network traffic data. The model identifies whether a network connection is normal or represents a potential cyber attack, helping improve network security and threat detection.

## ✨ Features

- Data preprocessing
- Feature engineering
- Model training and evaluation
- Network intrusion detection
- Prediction on new network traffic data

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📂 Dataset

The dataset contains network traffic features such as:
- Protocol type
- Connection duration
- Source and destination information
- Packet statistics
- Network activity attributes

## 🚀 How to Run

1. Clone this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

3. Open the Python script or Jupyter Notebook.
4. Run all the cells to train the model and perform intrusion detection.

## 📈 Output

The trained model classifies network traffic as **Normal** or **Intrusion (Attack)** based on the provided network features.
